# Antigravity Mission Control: unhcrreports

## 1. Project Identity & Strategic Goals

**Package Name:** unhcrreports **Purpose:** Automated generation of humanitarian statistical reports (Factsheets, Data Stories). **Primary Constraint:** Statistical Disclosure Control (SDC) is paramount. Never output raw counts < 5.

## 2. Architecture & Dependencies

**Status:** Migration in progress.

* **DEPRECATED:** `unhcrdatapackage`
* **REQUIRED:** `unhcrviz` (for plotting), `refugees` (for data), `ellmer` (for AI).
* **Guideline:** All plotting functions must return `ggplot2` objects. All data retrieval must go through the `refugees` package.

## 3. Coding Standards (Strict)

* **Style:** Tidyverse style guide (snake_case functions).
* **Documentation:** `roxygen2` for all exported functions. Examples must be executable.
* **Testing:** `testthat` coverage must exceed 80%. Mocks must be used for all LLM API calls.

## 4. AI & LLM Guidelines

* **Backend:** Use `ellmer` for all LLM interactions.^^ ** **
* **Safety:** Do not send PII (Personally Identifiable Information) to LLM APIs. Only aggregated statistics.
* **Cost:** Default to `gemini-1.5-flash` for high-volume tasks. Use `memoise` caching for all API calls.

## 5. Workflow Protocols

* **Planning:** Before editing code, generate an `Implementation Plan` artifact.
* **Execution:** After editing, run `devtools::check()`. If errors occur, analyze logs and fix.
* **Verification:** Generate a `Walkthrough` artifact explaining changes to the user.
